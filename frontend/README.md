# BIS Sahayak AI - Frontend

The web user interface for BIS Sahayak AI built with Next.js 16 (React 19) and Tailwind CSS.

- **Live Application:** [https://bis-sahayak-ai.netlify.app](https://bis-sahayak-ai.netlify.app)
- **Deployed on:** Netlify

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
